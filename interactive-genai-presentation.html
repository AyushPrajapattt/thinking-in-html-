01 · Foundations

What is Generative AI?

Generative AI learns patterns from examples and uses them to produce new content.

InputPrompt, context or other data
ModelLearned patterns and parameters
OutputText, images, audio, code and more

Generated content still needs evaluation; fluent output is not guaranteed truth.

03 · Architecture

Why attention matters

Self-attention lets each token use information from other positions in a sequence.

QueryWhat information is being sought?
KeyWhat information does another token offer?
ValueWhat content contributes to the result?

The Transformer architecture is built around attention mechanisms.

06 · Grounded generation

Retrieval-Augmented Generation

RAG retrieves relevant external information and supplies it as context to a generative model.

Question → Retrieve chunks → Add context → Generate
BenefitCan use relevant domain information.
DependencyRetrieval and source quality matter.

07 · Beyond chat

Agents and multimodal AI

Some applications connect models to tools and multi-step workflows. Multimodal systems process combinations of text, images, audio and video.

PlanBreak a goal into steps.
Use toolsCall an API or search service.
ObserveInspect results and decide next steps.

Tool use does not automatically make a system reliable or fully autonomous.

08 · Responsible use

Power needs evaluation

HallucinationsFluent outputs can include unsupported claims.
BiasData can reflect social biases.
PrivacyUnderstand data policies before sharing sensitive information.
Human reviewCheck important outputs against trusted sources.

Use AI to accelerate thinking, not replace verification.
