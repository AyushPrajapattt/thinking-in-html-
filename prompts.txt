PAGE 1 — ai-study-dashboard.html

Embed all CSS and JavaScript. Use accessible controls, keyboard support and mobile layout. No frameworks or external dependencies.

PAGE 2 — ai-tool-decision-helper.html
1. Build a responsive standalone AI Tool Decision Helper. Include five priority sliders with live values, a use-case filter, search field, weighted live ranking, reset and clear-filter controls, tool cards and a comparison table. Use clearly labelled illustrative sample profiles, not official benchmarks. Embed all CSS and JavaScript; no APIs or libraries.
2. Review weighted scoring and interactions. Ensure sliders immediately update values and rankings, filters work together, empty results are handled, and reset restores defaults.
3. Improve mobile responsiveness, keyboard access, focus styles, contrast and table overflow.
4. Check selectors, event listeners, score calculation and all controls. Ensure the page opens locally with no external dependencies.
